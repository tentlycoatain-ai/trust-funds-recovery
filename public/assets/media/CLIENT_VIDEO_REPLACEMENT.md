# Hero media replacement

Replace `financial-recovery-hero.mp4` with the approved client-owned 16:9 MP4 when it becomes available. Keep the filename and path unchanged so the Angular template requires no code change. The video should be muted, cinematic, restrained, and readable beneath the existing dark overlay. The local SVG poster remains the fallback if the browser cannot play the MP4.

No third-party remote media URL is used by the application.
